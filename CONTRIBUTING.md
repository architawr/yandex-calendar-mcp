# Участие в разработке

1. Создайте ветку и установите зависимости: `uv sync --locked`.
2. Добавьте осмысленные тесты для изменяемого поведения и выполните `uv run --locked pytest -q`.
3. Для изменений записи проверьте конфликты ETag, повторную отправку, предпросмотр, неизвестный сетевой результат и отсутствие побочных рассылок.
4. Выполните `uv build` и проверьте содержимое wheel и sdist.
5. Перед коммитом проверьте `git diff --cached` и список файлов. Не добавляйте локальный конфиг, календарные данные, резервные копии, токены, пароли или рабочие логи.

Тесты должны использовать подставные ответы. Не добавляйте реальные аккаунты или пароли в CI, фикстуры и примеры. Об уязвимостях сообщайте приватно по инструкции в SECURITY.md.

Изменения распространяются по лицензии MIT. README, пользовательские инструкции и описания изменений пишите на русском; имена API и программный код могут быть на английском.
